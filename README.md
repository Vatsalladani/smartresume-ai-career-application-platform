## 1. Product Overview

SmartResume.ai is not merely another generic AI resume text generator. Most AI career tools prompt a large language model to invent bullet points, embellish responsibilities, or hallucinate metrics that candidates cannot defend during an interview. 

SmartResume.ai is an integrated, full-lifecycle career platform designed around a single fundamental principle: **evidence-grounded career data**. The platform unifies the candidate journey from raw experience ingestion to final interview practice across eleven interconnected systems:

1. **Master Profile & Evidence Vault**: Central repository of verified work history, skills, projects, and credentials.
2. **Resume Builder**: Tailored draft generation with side-by-side diff acceptance and human-in-the-loop review.
3. **Template Library**: 14 structured, ATS-safe layouts across corporate, technical, academic, and creative domains.
4. **Job Fit Analysis**: Explainable requirement mapping that categorizes candidate qualifications into Strong, Partial, Missing, or Needs Review.
5. **Application Preparation**: Automatic generation of tailored cover letters, recruiter outreach messages, and application Q&A packets.
6. **SmartApply**: Manifest V3 browser extension assisting candidates with form fields on live job applications without background auto-submission.
7. **Application Tracker**: Kanban and lifecycle tracking for active job applications, versions, and interview dates.
8. **Interview Preparation**: Structured STAR-method behavioral and technical question generation based directly on the candidate's submitted resume and the target job description.
9. **Live AI Interview Practice**: Real-time voice and video practice simulation with explicit camera and microphone controls.
10. **Career Insights**: Domain readiness scoring, skill gap identification, and market positioning analytics.
11. **Billing & Subscriptions**: Transparent multi-currency pricing, one-time export purchases, and compliant subscription management.

The core differentiator is simple: **AI must work from verified candidate information instead of inventing experience, metrics, credentials, or achievements.**

## 2. Key Differentiator

## Why SmartResume.ai?

- **Master Profile as Single Source of Truth**: Candidate skills, accomplishments, projects, and employment history reside in verified records. Any resume bullet generated by the platform links back to genuine experiences.
- **Evidence-Grounded Generation**: When candidate data lacks evidence for a required qualification, the AI does not fabricate it. It highlights the gap and provides guidance on how to acquire or present genuine experience.
- **Zero Fabricated Achievements**: Eliminates the risk of interview embarrassment caused by generative AI hallucinations, fake percentages, and imaginary projects.
- **Explainable Job Matching**: Replaces arbitrary predictive percentage scores with deterministic, transparent requirement breakdowns showing exactly which requirements are satisfied and which are missing.
- **Job-Specific Resume Preparation**: Resumes are dynamically adapted for specific job postings while preserving master data integrity.
- **Immutable Resume Versioning**: Every exported resume snapshot is archived alongside its target job description, changelog, and template choice for future reference.
- **Interview Based on Submitted Resume**: Practice interview questions directly test the claims, technologies, and achievements stated on the specific resume version submitted to the employer.
- **Complete Workflow in One Platform**: Eliminates fragmented workflows between disparate resume builders, job boards, spreadsheets, and interview prep tools.

## 3. Product Workflow

```
Profile -> Resume -> Job Fit -> Application -> SmartApply -> Interview -> Tracking
```

1. **Profile**: Ingest existing resumes (PDF, DOCX, text) or manually input verified employment history, education, skills, and certifications into the Master Profile.
2. **Resume**: Select an ATS-safe template and generate structured resume drafts aligned with your career level.
3. **Job Fit**: Ingest target job descriptions; extract must-have and preferred requirements; evaluate candidate qualifications against each requirement.
4. **Application**: Review AI-proposed tailoring diffs with granular accept/reject controls; generate tailored cover letters and application answers.
5. **SmartApply**: Use the browser extension to autofill verified profile information on employer application portals with mandatory human review.
6. **Interview**: Defend claims through text-based STAR simulation and live voice/video practice rooms.
7. **Tracking**: Log submission dates, attached resume versions, interview milestones, and application outcomes.

## 6. AI Architecture & Safeguards

SmartResume.ai integrates Google Gemini (`gemini-3.6-flash`, `gemini-3.5-flash-lite`, and `gemini-2.0-flash-exp` for Live sessions) with strict engineering guardrails:

- **Structured Output Generation**: All AI endpoints enforce strict Pydantic schemas. Responses are parsed and validated as structured JSON, eliminating malformed outputs.
- **Anti-Fabrication Safeguards**: Prompts are constrained to verified candidate data in the Master Profile. When evidence is lacking, the model is instructed to flag an honest gap rather than invent metrics.
- **Designed to Keep Content Grounded**: Generated content is bound to verified profile evidence. The platform makes no unsubstantiated claims of "100% accuracy" or "zero hallucinations" and requires user review on all proposed changes.
- **Prompt Injection Defense**: Input sanitization strips markdown fences and analyzes job descriptions and resume text against known prompt injection patterns (`detect_prompt_injection`).
- **Deterministic Local Fallback**: When Gemini API credentials are not configured, the platform executes a local rule-based analysis engine (`_local_analysis`), ensuring zero application downtime or unexpected crashes.

## 7. Job Fit Engine

SmartResume.ai rejects misleading predictive "ATS scores." Instead, it provides an explainable, deterministic qualification mapping:

```
Job Description -> Requirement Extraction -> Evidence Mapping -> Categorized Ratings
```

1. **Requirement Extraction**: The engine parses the job posting into categorized requirements tagged as `MUST_HAVE` or `PREFERRED`.
2. **Evidence Mapping**: Candidate experiences, skills, and projects are cross-referenced against each requirement.
3. **Four-Part Classification**:
   - **Strong Match**: Directly backed by verifiable work experience bullets and matching skills.
   - **Partial Match**: Related experience or transferrable skills identified, but lacking direct evidence.
   - **Missing Gap**: Requirement is not represented in the candidate's profile.
   - **Needs Review**: Ambiguous or unquantified claims requiring candidate verification.
4. **Explainable Breakdown**: A transparent score composite based on Evidence Match (40%), Keyword Coverage (30%), Format Health (15%), and Content Quality (15%).

## 10. SmartApply Browser Extension

The platform includes a dedicated Chromium extension built on **Manifest V3** located in `smartapply-extension/`:

- **Field Assistance**: Detects supported application forms (LinkedIn, Indeed, Glassdoor, Naukri, Greenhouse, Lever, Workday) and offers one-click filling of verified personal details, education, and work history.
- **Resume Version Selection**: Allows candidates to select from their stored immutable tailored resume versions.

- **Secure Token Communication**: Authenticates against the local or remote SmartResume.ai API using the candidate's active session token.

## 11. Authentication & Identity

- **Email & Password**: Bcrypt password hashing (12 salt rounds), strict complexity validation (minimum 8 characters with uppercase, lowercase, numeric digit, and special symbol), account lockout after 5 consecutive failed attempts, and single-use password reset tokens with 20-minute expiration.
- **Email Verification**: Transactional verification emails dispatched on registration via standard SMTP relay (`email_service.py`), with honest server-log fallback when unconfigured.
- **Session Management**: Dual-token architecture with short-lived access tokens (15 minutes) and single-use refresh tokens (14 days) featuring automatic token rotation and server-side blacklisting upon logout (`token_blacklist`).
- **Social OAuth 2.0 (Google & LinkedIn)**: Complete backend routing (`/auth/oauth/google`, `/auth/oauth/linkedin`), account linking logic, and state verification implemented in code. Operates with friendly setup notices when client credentials are not configured in `.env`.

## 12. Security Protections

SmartResume.ai implements comprehensive application-layer security verified by automated testing:

- **Password Security**: Bcrypt password hashing with unique salt per user; complex regex validation.
- **JWT Protection**: Tokens signed via HS256/RS256; secrets validated at startup to reject insecure defaults or short strings (< 32 characters) in production mode.
- **Rate Limiting**: Sliding-window rate limiting middleware (`SimpleRateLimitMiddleware`) with granular route budgets: 10 req/min for auth, 15 req/min for AI/jobs, and 120 req/min for general endpoints, with preflight `OPTIONS` bypass.
- **Request Size Limiting**: `RequestSizeLimitMiddleware` rejects payloads exceeding 12 MB with HTTP 413, preventing memory exhaustion attacks.
- **Security Headers**: `SecurityHeadersMiddleware` injects `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`, and `Permissions-Policy: camera=(), microphone=(), geolocation=()`.
- **CORS Isolation**: Whitelisted origin matching against explicit domains (`settings.allowed_origins`); wildcard `*` with credentials is explicitly forbidden.
- **Anti-Enumeration**: Forgot-password endpoint returns an identical generic confirmation message regardless of whether an email address exists in the database.
- **Payment Verification**: Webhook payloads verified via HMAC-SHA256 signatures (`X-Razorpay-Signature`); processed events recorded in an idempotency ledger (`PaymentEvent`) to eliminate duplicate credit allocation.

## 16. Local Setup Instructions (Windows / PowerShell)

### Prerequisites
- **Python**: 3.12 or higher installed and added to `PATH`
- **PostgreSQL**: 15 or higher running locally on port 5432, or Docker
- **Node.js** (optional): for static serving, or use Python's built-in `http.server`

### 1. Clone the Repository
```powershell
git clone https://github.com/Vatsalladani/smartresume-ai-career-application-platform.git
cd "smartresume-ai-career-application-platform"
```

### 2. Configure Environment Variables
```powershell
Copy-Item .env.example .env
```
Open `.env` and verify database credentials:
```env
DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5432/resume_saas_db
JWT_SECRET_KEY=dev-secret-change-before-production-64-characters-minimum-for-security
ENVIRONMENT=development
ALLOWED_ORIGINS=["http://127.0.0.1:3000","http://localhost:3000","http://127.0.0.1:5500","http://localhost:5500"]
```

### 3. Set Up Python Virtual Environment
```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 4. Initialize Database
Ensure PostgreSQL is running and create the database if needed:
```sql
CREATE DATABASE resume_saas_db;
```
Apply database migrations using Alembic:
```powershell
alembic upgrade head
```

### 5. Start the Backend Server
```powershell
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
Verify the backend is running by accessing `http://127.0.0.1:8000/health`.

### 6. Start the Frontend Server
Open a new PowerShell terminal, navigate to the repository root, and run:
```powershell
python -m http.server 3000 --directory frontend
```
Open `http://127.0.0.1:3000` in your browser.

### 7. Load the SmartApply Extension (Optional)
1. Open Google Chrome or Microsoft Edge and navigate to `chrome://extensions` (or `edge://extensions`).
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select the `smartapply-extension/` directory.

## 23. Transparent Limitations

- **External Credentials**: Full live operation of cloud AI, social OAuth login, external job aggregation, and live payment processing requires external API keys configured in `.env`. The platform operates gracefully with local deterministic engines when keys are absent.
- **Job Feeds**: Job discovery relies on database postings and curated seed listings unless external job provider APIs (Adzuna / RapidAPI) are enabled.
- **Payment Mandates**: UPI AutoPay requires bank app authorization per National Payments Corporation of India (NPCI) guidelines; recurring card mandates follow Reserve Bank of India (RBI) e-mandate regulations.
- **Live AI Interview**: Voice and video simulation requires browser camera and microphone permissions and an active network connection to Google Gemini Live endpoints.
